# Weekly status outline

Follow this shape:

```
Weekly status: <Monday date> to <Sunday date>

Highlights
- one to three lines on the most important outcomes

Done
- <item>: <result>

In progress
- <item>: <where it stands>

Blocked (only if the includeBlocked setting is on)
- <item>: <what is in the way>

Notes
- <the kbUrl link, if one is set>
```

Leave out any section that has nothing in it.
